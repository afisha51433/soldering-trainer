# ⚡ 電子焊接模擬器 (Virtual Soldering Lab)

做了一個焊接模擬器，練習焊出完美的焊點!

學生在實際拿起高溫電烙鐵之前，可以先透過瀏覽器、電腦鍵盤或平板雙手觸控，像玩節奏遊戲一樣反覆練習「擦海綿 ➔ 預熱 3 秒 ➔ 送焊錫 ➔ 先收焊錫 ➔ 再提烙鐵」的標準動作與手感！

## ✨ 專案特色

- **🔬 擬真焊接物理與即時視覺回饋**
   - **烙鐵頭氧化與清潔**：烙鐵頭使用一段時間會氧化變暗並降低導熱效率，點擊濕海綿會產生蒸氣音效並恢復銀亮光澤。
   - **預熱時機與溫度判定**：預熱不足（`< 2.5s`）送錫會導致「冷焊」；加熱過久（`> 5.2s`）會使焊點氧化黯淡甚至讓 PCB 焊盤焦黑。
   - **焊錫形態動態演變**：隨著送錫量變化，焊點會從「少錫未包覆」➔「光亮凹面小山（`45% ~ 72%`）」➔「過量圓球狀（`> 78%`）」即時呈現。
   - **撤離順序偵測**：若在送焊錫時「先提起電烙鐵、才放開焊錫絲」，焊點會被拉出尖刺（拉尖）並扣分。
- **✋ 右撇子 / 🤚 左撇子一鍵鏡像切換**
   - 支援即時切換慣用手模式，畫面上的電烙鐵（右傾 `/` 或左傾 `\`）、焊錫絲、濕海綿位置、下方操作按鈕與所有步驟提示都會同步鏡像翻轉。
- **🎓 教學輔助 / 🏆 實戰測驗雙模式**
   - **教學輔助模式**：畫布中央上方提供大型高對比計量條（預熱時間、焊錫量、烙鐵頭潔淨度）與即時教練引導橫幅，幫助初學者精準掌握節奏。
   - **實戰測驗模式**：隱藏所有數值計量條，考驗學生透過焊錫光澤、煙霧變化與 Web Audio API 合成音效進行盲測判斷。
- **🏅 五點檢定與即時縮圖成績單**
   - 連續完成 `J1 ~ J5` 五個焊點後，系統會自動生成「電子焊接技能檢定成績單」，附上每個焊點的實際外觀縮圖、分數、S～D 綜合等第與個人化改進建議。
- **📦 單檔零外部相依**
   - 100% 採用原生 HTML5 Canvas、CSS3 與 Vanilla JavaScript 開發，無需安裝任何套件或網路字型，離線也能流暢執行。

## 📖 標準焊接五步驟（課堂教學口訣）

1. **一擦（清潔）**：焊接前先用濕海綿擦拭烙鐵頭，確保表面銀亮無氧化層（潔淨度 `≥ 75%`）。
2. **二熱（預熱）**：將烙鐵頭同時靠在銅箔焊盤與元件接腳上，預熱約 **2.5 ~ 3.8 秒**。
3. **三錫（送錫）**：保持烙鐵加熱不動，從另一側送入焊錫絲，直到熔化的焊錫形成飽滿光亮的**凹面小山（45% ~ 72%）**。
4. **四撤錫（先收焊錫）**：焊錫量足夠時，**先將焊錫絲撤離**（放開送錫鍵），讓烙鐵繼續停留約 `0.3` 秒使焊點圓潤。
5. **五提鐵（再提烙鐵）**：最後才將電烙鐵提起（放開烙鐵鍵），完成一顆完美的焊點！

## 🚀 如何部署到 GitHub Pages（讓學生直接開啟網址使用）

只需要 3 個步驟，就能免費將這個小工具發佈成公開網頁供全班學生使用：

1. **建立 Repository**：登入 GitHub，點擊右上角 `+` ➔ `New repository`，輸入專案名稱（例如 `soldering-trainer` 或 `virtual-soldering-lab`）並設為 `Public`。
2. **上傳檔案並命名為 `index.html`**：將模擬器的 HTML 檔案重新命名為 **`index.html`**，連同這份 `README.md` 一起上傳至專案根目錄。
3. **開啟 GitHub Pages**：
   - 進入專案的 **Settings（設定）** ➔ 左側選單 **Pages**。
   - 在 **Build and deployment** 下的 `Branch` 選擇 **`main`** 與 **`/ (root)`**，點擊 **Save**。
   - 等待約 1 分鐘後重新整理頁面，上方就會出現專屬網址（格式為 `https://<你的帳號>.github.io/<專案名稱>/`），把網址或 QR Code 分享給學生就能直接開始練習！

## 🛠️ 教師自訂參數說明

若老師想依據不同年級或課程難度調整判定標準，可以直接開啟 `index.html` 搜尋以下關鍵數值進行微調：

- **最佳預熱時間區間**：搜尋 `j.heatTime <= 3.8`（預設最佳區間為 `2.5s ~ 3.8s`）。
- **過熱氧化警戒時間**：搜尋 `j.heatTime > 5.2`（預設超過 `5.2s` 開始扣分並產生焦黑特效）。
- **完美焊錫量區間**：搜尋 `amt >= 45 && amt <= 72`（預設 `45% ~ 72%` 為標準凹面小山）。
- **每輪練習焊點數量**：搜尋 `const TOTAL_JOINTS = 5;`（可改為 `3` 或 `10` 點）。
